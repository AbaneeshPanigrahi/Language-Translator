# Language Translator

## Project Description

Language Translator is a web application built using HTML, CSS, and JavaScript. It allows users to translate both text and PDF files into different languages quickly and easily. The application provides a simple and clean interface for better user experience.

## Features

* Text translation
* PDF file translation
* Multiple language support
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter the text or upload a PDF file.
2. Select the source and target languages.
3. Click the translate button.
4. View the translated result instantly.

## Purpose

This project was developed to demonstrate front-end development skills, API integration, and file handling using JavaScript.
