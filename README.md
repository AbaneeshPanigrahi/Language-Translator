## Overview

Language Translator is a web application built using HTML, CSS, and JavaScript that supports both text and PDF translation. Users can enter text or upload a PDF file to translate content into different languages instantly.

The project demonstrates practical frontend development skills including API integration, file handling, and dynamic UI behavior in a responsive interface.

---

## Features

- Text-to-text translation
- PDF upload and translation support
- Multiple language selection
- Instant translation output
- Responsive, user-friendly design
- Clean and interactive frontend experience

## Getting Started

### Prerequisites

- Modern web browser
- Optional: local web server for easier testing

### Run Locally

```bash
git clone https://github.com/AbaneeshPanigrahi/Language-Translator.git
cd Language-Translator
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

> If the app uses a translation API, configure the required API key and endpoint details in the JavaScript code before running it.

---

## How It Works

1. The user enters text or uploads a PDF file.
2. They choose the target language.
3. The frontend communicates with the translation service.
4. The translated content is displayed instantly in the browser.
